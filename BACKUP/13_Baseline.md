# 拿到需求的基准流程 

- [ ] 先测试外部`API`及参数，反馈缺失项给技术支持，避免开发阻塞
- [ ] 利用AI辅助判断和拆解需求
- [ ] 熟悉项目代码，优先复用已有实现，避免重复造轮子：
   - [ ] 定制需求检查是否有类似代码可复用
   - [ ] 唯一定制可考虑硬编码参数，或添加进环境配置项
   - [ ] 防御性编程：处理字段为空或无法取值的情况
- [ ] 优先本地测试，验证通过后再部署生产
- [ ] 客户服务有白名单时，通过`SSH`或`VPN`连接测试
- [ ] 注意代码质量和`Git`单向性，避免冲突
